# Общая структура файла с кодом

При работе с библиотекой PyGame Zero, во время написания кода лучше придерживаться определенной структуры, чтобы в игре было проще ориентироваться. Ниже приведен файл с примерным расположением частей программы в играх с PyGame Zero:

```py
# Подключение библиотеки
import pgzrun

# Постоянные (например, ширина и высота окна)
WIDTH = 800
HEIGHT = 600

# Переменные (например, гравитация, игровые актеры)
gravity = 0.5
bird = Actor("bird")

# Функция обработки нажатия клавиш
def on_key_down(key):

    pass

# Функция обновления игры
def update():

    pass

# Функция отрисовки экрана
def draw():

    pass
```

Остановимся на каждой из трех функций:

## Функция обработки нажатия клавиш
### `def on_key_down(key):`

Эта функция запускается PyGame Zero каждый раз, когда нажата какая-либо из клавиш. Нажатая клавиша содержится в параметре `key`, и её можно сравнивать с помощью `==` с клавишами, перечисленными в объекте `keys`. Например, чтобы вывести в консоль смайлик, если только что была нажата клавиша пробел, можно написать:

```py
def on_key_down(key):

    if (key == keys.SPACE):

        print(":)")
```

## Функция обновления игры
### `def update():`

Эта функция запускается PyGame Zero на каждый игровой кадр; то есть, ровно 60 раз в секунду. Внутри этой функции находится основная логика игры.

## Функция отрисовки экрана
### `def draw():`

Эту функцию PyGame Zero запускает, когда считает нужным обновить картинку на экране. Это может происходить до шестидесяти раз в секунду, то есть, каждый игровой кадр, но также это может не случаться, если в игре ничего не происходит.

Поскольку PyGame Zero старается оптимизировать отрисовку игровой графики — то есть, запускать эту функцию минимально возможное количество раз — в эту функцию нельзя помещать игровую логику, такую, как перемещение персонажей или обработка нажатий клавиш.

# Экран и графика

PyGame Zero предоставляет возможность и ответственность программисту самому определять, как происходит отображение графики на экране игрока, и какой. Это происходит с помощью написания функции `draw()`, от поведения которой зависит то, что появится на экране. В PyGame Zero для этого есть специальный объект, используемый для отрисовки графики — `screen`.

## Очистка экрана (заполнение чёрным)
### `screen.clear()`

Вызов этой функции внутри `draw()` приводит к тому, что экран заполняется черным цветом.

## Заливка экрана цветом
### `screen.fill((<красный>, <зеленый>, <синий>))`

Эта функция, в отличие от `screen.clear()`, заполняет весь экран определенным цветом. Этот цвет определяется тремя числами от `0` до `255`, записанными в скобках внутри скобок функции через запятую. Например, чтобы залить экран белым, используется следующий код:

```py
def draw():

    screen.fill((255, 255, 255))
```

## Отрисовка изображения на экране
### `screen.blit("<имя_изображения>", (<x>, <y>))`

Эта функция отрисовывает изображение на экране. В качестве первого параметра функции передается имя изображения без расширения (то есть, для файла `background.png` мы написали бы `"background"`). Это изображение должно находиться в папке `images` внутри папки проекта. Вторым параметром передаются координаты *левого верхнего угла* изображения в скобочках через запятую. 

Например, чтобы нарисовать изображение `background.png` так, чтобы его левый верхний угол был бы в левом верхнем углу окна, мы написали бы следующий код:

```py
def draw():

    screen.blit("background", (0, 0))
```

# Актёры

В PyGame Zero основными игровыми объектами являются **актёры** — как спрайты в Scratch. Их можно создать, у них есть свойства и функции, используя которые можно придать им различное поведение.

## Создание актёра
### `<имя_переменной> = Actor("<имя_спрайта>")`

Для того, чтобы создать актёра, воспользуйтесь функцией `Actor()` (обязательно с большой буквы!). Такая функция называется *конструктором*, потому что её задача в первую очередь создать объект (актёра в данном случае).

В качестве параметра функции передается имя спрайта актёра без расширения (то есть, для файла `bird.png` мы написали бы `"bird"`). Этот спрайт должен находиться в папке `images` внутри папки проекта.

## Координаты актёра
### `<актёр>.x`
### `<актёр>.y`
### `<актёр>.pos`

Для перемещения актёра по сцене можно задавать ему числовые координаты с помощью свойств `x`, `y` и `pos`. Свойство `pos` содержит обе координаты сразу, а свойства `x` и `y` содержат координаты по одной — однако они всегда содержат одни и те же числа.

Чтобы переместить актёра только по одной из осей координат, можно прибавить, отнять или присвоить значения свойствам `x` и `y`. Свойство `pos` используется для записи или получения обеих координат сразу, и в него они записываются в скобочках. Например:

```py
bird = Actor('bird')
bird.pos = (100, 100) # Координаты x и y в скобочках
```

## Отрисовка актёра на экране
### `<актёр>.draw()` (внутри функции `draw()`)

Актёра недостаточно только создать. Чтобы актёр появился на экране, его необходимо отобразить с помощью вызова функции `draw()` у актёра. При этом, это нужно делать внутри функции отрисовки экрана (т.е. `draw()`). Например:

```py
bird = Actor('bird')

def draw():

    bird.draw()
```

# Возможности и особенности при работе с PyGame Zero 

## Проверка нажатия клавиши
### `if (keyboard.<клавиша>):`

Поскольку `on_key_down()` вызывается только тогда, когда клавиша была непосредственно нажата, мы не можем с её помощью определить поведение, если клавиша *удерживается* — для этого мы можем проверять нажатие клавиши внутри функции `update()` с помощью `if`-а. 

Например, приведенный код ниже выводит смайлик каждый кадр, во время которого нажата клавиша пробел:

```py
def update():

    if (keyboard.space):

        print(":)")
```

## Глобальные переменные
### `global <переменная>, <переменная>, ...`

Если мы объявили какие-то переменные для нашей игры (так чаще всего и случается), то скорее всего мы захотим ими воспользоваться внутри игровых функций (`update()`, `on_key_down()` или `draw()`). Однако, поскольку внутри функций существуют также временные переменные, нам необходимо указать Python-у, что мы используем глобальные переменные, существующие за пределами функции. Для этого, необходимо написать в начале функции слово `global`, а затем перечислить используемые глобальные переменные через запятую.

Например, если у нас есть переменная `counter`, которую мы хотим увеличивать каждый игровой кадр, мы можем написать такой код:

```py
counter = 0

def update():
    global counter

    counter += 1
```
